# Hexcat

![GitHub License](https://img.shields.io/github/license/mattaroni/hexcat)
![GitHub Release](https://img.shields.io/github/v/release/mattaroni/hexcat)
![Rust Version](https://img.shields.io/badge/dynamic/toml?url=https%3A%2F%2Fraw.githubusercontent.com%2Fmattaroni%2Fhexcat%2Frefs%2Fheads%2Fmain%2FCargo.toml&query=%24.package.rust-version&label=rust)

Prints the contents of a file as hexadecimal bytes.

## Usage

> [!NOTE]
> Be sure to have [Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)
> installed.

Use the command below to compile and install the binary.

```
cargo install --git https://github.com/mattaroni/hexcat.git
```
